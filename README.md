# Dicebound

## Português

Dicebound é um aplicativo de gerenciamento de fichas digitais de personagens de RPG, criado para facilitar a organização, o gerenciamento e a edição de múltiplas fichas entre diferentes sistemas de RPG.

### Features

- Suporte a Dungeons & Dragons e Ordem Paranormal;
- Troca fluida entre sistemas;
- Criação, edição e exclusão de fichas;
- Armazenamento local;
- Interface bilíngue (PT-BR e EN);
- Cálculos automáticos.

### Stack

- React;
- TypeScript;
- Vite;
- CSS Modules;
- Playwright;
- ESLint.

---

## English

Dicebound is a digital RPG character sheet management application designed to make it easier to organize, manage, and edit multiple character sheets across different RPG systems.

### Features

- Support for Dungeons & Dragons and Ordem Paranormal;
- Seamless switching between systems;
- Character sheet creation, editing, and deletion;
- Local storage;
- Bilingual interface (PT-BR and EN);
- Automatic calculations.

### Stack

- React;
- TypeScript;
- Vite;
- CSS Modules;
- Playwright;
- ESLint.
